## 주의 — 이 시스템의 계약은 "진짜 백엔드"와 다릅니다

부록B의 API 계약은 **이 임시 테스트 시스템 전용**입니다. 팀의 진짜 백엔드
(`agent-vibe-coding-starter-kit2`로 개발)는 경로·인증 헤더·데이터 모델이 전부 달라서
여기서 만든 `client.py`가 그대로 붙지 않습니다. 갈아타는 절차는 **03**을 따르고,
백엔드 담당 학생은 `agent-vibe-coding-starter-kit2`의
`docs/부록D-iot-test-system-연동-가이드.md`를 함께 봅니다.
