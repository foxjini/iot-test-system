# 워크플로우: 백엔드 연결 확인하기

1. 백엔드 PC(Windows)의 LAN IP를 확인한다 (`ipconfig` → IPv4 주소).
2. 라즈베리파이에서 `curl http://<백엔드IP>:8000/api/health`로 기본 접속을 확인한다.
   실패하면 백엔드가 `--host 0.0.0.0`로 켜져 있는지, Windows 방화벽에서 8000번
   포트 인바운드가 허용되어 있는지 확인한다.
3. 대시보드(`http://<백엔드IP>:3000`)에서 디바이스를 등록하고 `device_id`/`api_key`를
   확인한다 (없다면 새로 등록).
4. `.env`에 `BACKEND_URL`, `DEVICE_ID`, `API_KEY`를 채운다.
5. 코드 실행 전 `heartbeat()` 호출만 먼저 테스트한다 — 성공하면 대시보드에서
   해당 디바이스가 "온라인"으로 바뀌는지 확인한다.
6. `list_components()`가 대시보드에 등록한 컴포넌트 목록과 일치하는지 확인한다.
7. 센서 하나를 `push_telemetry()`로 올려 대시보드 카드에 값이 뜨는지 확인하고,
   액추에이터 하나를 대시보드에서 "적용"해 라즈베리파이가 `pending_commands()`로
   받아 실행하는지 확인한다.
8. 401 오류가 나면 `DEVICE_ID`/`API_KEY`가 정확한지(공백 없이) 다시 확인한다.
